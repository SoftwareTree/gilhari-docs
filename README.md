# Gilhari Documentation

Shared reference documentation for Gilhari, the microservice framework that exposes JSON objects persisted in a database through a REST API. The same material applies when Gilhari is used through ORMCP Server.

Gilhari sample projects, ORMCP Server documentation and other Software Tree repositories link to the documents here instead of each keeping its own copy, so a document is maintained in one place.

## Reference

| Document | Description |
|---|---|
| [operationDetails Parameter](reference/operationDetails.md) | How to use the `operationDetails` parameter of query operations to refine the shape and scope of returned objects (`projections`, `ignore` and `follow` for object references, and `filters` on objects of specific types), similar to GraphQL capabilities |
